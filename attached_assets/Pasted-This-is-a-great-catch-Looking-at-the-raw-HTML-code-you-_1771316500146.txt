Here are the **3 Critical Technical Issues** in your code that are hurting your SEO visibility right now:

### 1. The "Invisible Website" Problem (Critical)

Your site uses a scroll animation library (likely Framer Motion or AOS) that fades elements in as the user scrolls.

* **The Code Issue:** In your HTML, many important sections have the inline style: `style="opacity: 0;"`.
* *Example from your code:* `<div class="md:w-1/2 order-2 md:order-1" style="opacity: 0; transform: translateX(-30px);">`


* **Why Google Hates It:** When Googlebot crawls your page, it doesn't "scroll" like a human. It often just takes a snapshot. If your JavaScript doesn't fire instantly to change that `opacity: 0` to `opacity: 1`, **Google sees an empty white page.**
* **The Fix:** You need to set the default CSS to visible, or use a "no-js" fallback.
* *Quick Fix:* Change your CSS/JS so elements default to `opacity: 1` and only hide if the animation script successfully loads.

### 3. The "Age Gate" Obstacle

You have an Age Verification popup (`<div class="fixed inset-0 bg-black/90 ...">`).

* **The Issue:** While allowed for vape shops, yours is a "full screen blocker" in the DOM. Combined with the `opacity: 0` issue on the main content, Google might think your *entire website* is just a black popup with "Age Verification" and no actual content (products, location, etc.).
* **The Fix:** Ensure your main content (`<main>`) is fully rendered in the HTML *behind* the popup (which it is), but **fix the opacity issue** mentioned in #1 so Google can "see through" the popup to read your text.
